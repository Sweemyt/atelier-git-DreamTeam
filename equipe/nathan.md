## Quiz

1. Juste après `git commit`, où se trouve mon commit ?
Le commit se trouve sur mon codespace, bien enregistré.

2. Juste après `git push`, où se trouve-t-il ?
Il se trouve sur github, là où tous les collaborateurs ont accès et peuvent récupérer mon travaille.

3. Que se passe-t-il si je supprime mon Codespace après un commit mais sans push ?
Le commit n'est pas push dont perdu et peut-être avec toutes les modifications effectuées.
